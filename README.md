# 🤖 Admin Support & Broadcast Bot

A custom, open-source Telegram bot designed for seamless customer support and user engagement. This bot acts as a bridge between users and administrators, keeping the admin's identity completely private.

## 🌟 Key Features
* **💬 Two-Way Communication:** Users can send messages to the bot, and admins receive them in a private chat.
* **🕵️‍♂️ Admin Privacy:** Admins can reply directly to user messages without revealing their personal Telegram account.
* **📢 Mass Broadcasting:** Admins can send announcements or updates to all users who have interacted with the bot.
* **⚡ Fast & Lightweight:** Built using Node.js and Telegraf.

## 🛠️ Tech Stack
* **Language:** JavaScript (Node.js)
* **Framework:** Telegraf
